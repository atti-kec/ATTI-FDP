FDP Outcome 

By the end of 6 days, participants will be able to: 

- Implement HDFS-based distributed storage 

- Query large datasets using Hive 

- Integrate relational databases using Sqoop 

- Process large datasets using Apache Spark 

- Implement real-time streaming using Kafka 

- Build ML models using Spark MLlib 

- Visualize large-scale data using ELK 

- Develop an end-to-end Big Data + AI/ML application
